# Garimpo (v1.0.0)

Pipeline: vídeo → WAV → transcrição (.md, tempo por palavra e frame) → correção com dicionário do usuário → análise (frases → parágrafos → temas, um .md cada) → sugestão de cortes (30 s a 1min30, sem cortar frases, prévia em WAV) → validação → corte em MP4 máxima qualidade, vertical 9:16 → legenda dinâmica palavra por palavra (Lato, maiúsculas).
