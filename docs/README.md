## Estrutura
- `apps/launcher`: Launcher (Electron), instala e atualiza o app
- `apps/desktop`: ATTO Tools (Electron + React)
- `apps/engine`: motor Python do Garimpo (uv)
- `scripts/release`: gera o `manifest.json` das releases
- `website`: página de apresentação (GitHub Pages)
